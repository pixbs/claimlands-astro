# Claim Lands

Public repository for a procedural planetary strategy game on iOS, Android and
browser WebAssembly. Original work is licensed under CC BY-NC-SA 4.0.

This initial commit establishes trusted repository governance and automated gates.
The Rust application and world contracts arrive through the foundation PR tracked
in [issue #1](https://github.com/pixbs/claimlands-astro/issues/1).

Read [AGENTS.md](AGENTS.md) before contributing. Every PR requires current automated
validation, a preview of the actual game, independent review and manual owner acceptance.
The first visual baseline and deployment credentials remain owner setup steps.
